# 商务写作提示（报告、提案、邮件）

> 使用场景：撰写或修改商务报告、提案、计划书、商业邮件、内部备忘录等。
> 目标：清晰、有力、行动导向，同时保持专业形象。

## 核心要点

1. **姿态**：你是在向决策者展示一个事实或建议，不是自我辩护。读者是忙碌的、有能力的人，他们需要快速抓住要点。直接呈现结论，隐藏过程性细节（除非必要）。

2. **行动导向**：商务写作通常有明确目的——说服、通知、请求。开头就要点明核心信息（结论或建议），后面再提供支持。

3. **角色与动作**：明确谁做什么。不要写“一项决策被作出”，要写“董事会决定……”。用主动语态，让责任人清晰。

4. **简洁与直白**：删掉一切不必要的客套和套话。例如：
   - 坏：`我们特此通知贵方，关于贵方所提交之提案，经我方审慎评估后，认为尚需进一步修改。`
   - 好：`我们已审阅您的提案，还需修改后才能批准。`

5. **信息流**：先给结论，再给理由。每段第一句就是该段核心。

6. **主题链**：段落内保持主语一致，避免频繁切换话题。

7. **语气**：用“你”和“我们”建立对话感。不要过度使用“贵方”“我方”。保持自信但不傲慢。

## 结构模板

### 商务报告

```
执行摘要（核心结论+建议）
背景（简要）
发现与分析（每段一个要点，点句开头）
建议与行动（明确谁做什么、何时完成）
```

### 商务邮件

```
主题行：直接写出邮件目的（如“关于XX项目的预算审批”）
开头：直接说明来意
中间：必要细节（分点列出）
结尾：明确的下一步行动（“请于周五前回复确认”）
```

## 禁用事项

- [ ] 不要用“在此”“兹”“特此”等过时套话
- [ ] 不要绕圈子，开头就写目的
- [ ] 不要用“可能”“或许”堆砌
- [ ] 不要写“我想借此机会表达……”之类的寒暄
- [ ] 不要用被动语态隐藏责任人
- [ ] 不要把简单的事情说得复杂（“为了实现我们的目标，我们需要……”→“为了达到目标，我们需要……”）
