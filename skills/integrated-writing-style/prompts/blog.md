# 博客与评论写作提示

> 使用场景：撰写或修改博客文章、公众号文章、评论、专栏、个人随笔等面向大众的非虚构写作。
> 目标：清晰、有趣、有观点，与读者建立平等对话。

## 核心要点

1. **姿态**：你是一个有趣的讲述者，把读者当作朋友，分享你发现的事物。不要好为人师，不要卖弄，不要用学术腔。

2. **开头**：直接进入主题或用一个具体场景/故事引入。不要用“在当今社会……”“随着……的发展”开头。

3. **问题与代价**：即使是非学术文章，也要让读者知道“为什么值得读”。可以在开头或前几段点明你要讨论的问题及其重要性。

4. **展示而非说教**：用具体例子、故事、比喻来呈现观点。让读者自己得出结论，而不是直接灌输。

5. **主题链**：段落内保持话题一致，让读者轻松跟随。

6. **简洁与节奏**：句子可短可长交替，但避免连续长句。删除无意义修饰语（“真的、非常、特别”）。让每个词都有力量。

7. **人称**：多用“你”“我”“我们”，营造对话感。

## 结构模板

### 评论/观点文章

```
钩子（一个故事、一个场景、一个惊人事实）
背景（简要交代背景，让读者进入语境）
问题（你要讨论的现象/问题，以及为什么重要）
分析/论述（分几个点，每段一个要点，点句开头）
结论（重申观点，或提出行动呼吁）
```

## 禁用事项

- [ ] 不要用“众所周知”“不可否认”等套话
- [ ] 不要用“总而言之”“综上所述”开头结论（直接用有力句子）
- [ ] 不要堆砌网络流行语（除非有明确效果）
- [ ] 不要写“我个人认为”重复强调（观点已经在文中）
- [ ] 不要用“的、地、得”过度纠结（除非正式要求）
