# 科学写作与科普提示

> 使用场景：撰写或修改科学论文、研究报告、科普文章、科学新闻、技术文档等。
> 目标：把复杂的科学概念讲清楚，让目标读者（科学家或公众）理解并感兴趣。

## 核心要点

1. **克服知识的诅咒**：你比读者更熟悉术语和概念。首次引入术语时，用一句话解释。用具体意象替代抽象名词。

2. **展示而非陈述**：描述实验过程、观察结果时，让读者“看见”发生了什么。不要只说“结果显著”，说“结果之间的差异是偶然产生的概率小于5%”。

3. **角色与动作**：让研究主体（研究对象、细胞、数据、我们）作主语，动词表达动作。避免“进行实验”“实施测量”等冗余。
   - 坏：`对样品进行了分析。`
   - 好：`我们分析了样品。`

4. **信息流**：先已知后未知。例如，先说“黑洞是……”再引入新发现。

5. **结构**：科学论文有严格结构（IMRaD），但每个部分内部仍遵循“点句预告”原则。科普文章可采用“问题—探索—发现”叙事结构。

6. **简洁**：删除“在一定程度上”“可能”“似乎”等模糊缓冲。用精确限定替代（“在95%置信区间下”优于“基本上”）。删除“非常”“高度”等无意义强调词。

7. **比喻和类比**：可以用于科普文章，帮助读者建立意象，但要确保准确。

## 结构模板

### 科学论文（IMRaD）

```
引言：背景 → 问题 → 假设/目的
方法：实验设计、材料、过程（简洁，可略读）
结果：呈现数据，每段一个发现
讨论：解释发现、对比已有研究、提出意义
```

### 科普文章

```
钩子：一个有趣的事实或问题
背景：让读者理解为什么这个问题值得关注
解释：分步骤揭示科学原理（每段一个要点）
启示：对读者意味着什么
```

## 禁用事项

- [ ] 不要堆砌缩写（首次出现必须给出全称）
- [ ] 不要用“众所周知”开头
- [ ] 不要写“本研究首次……”（除非确凿且有文献支持）
- [ ] 不要用“某种程度”“可能”等模糊词代替精确统计
- [ ] 不要用被动语态逃避责任（“样本被处理”可以，但“结论被得出”不好）
- [ ] 不要过度使用“显著”“重要”作为万能修饰语
