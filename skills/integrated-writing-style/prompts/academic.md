# 学术论文写作提示

> 使用场景：撰写或修改学术论文、研究报告、学位论文、学术评论等。
> 目标：在保持学术严谨性的同时，实现清晰、连贯、优雅的表达。

## 核心要点

1. **姿态**：你是研究者，也是导游。把研究发现当作“你看见的真相”展示给同行读者，但不要炫耀术语或堆砌文献。读者是聪明的同行，但可能不熟悉你的具体领域——避免知识的诅咒。

2. **结构与引言**：采用 Williams 的问题—代价—解答三段式。
   - 共享语境：简述研究背景，让读者进入你的领域。
   - 问题：明确指出当前研究的缺口（条件）+ 不解决的后果（代价）。
   - 解答/论点：你的研究问题、假设或贡献。
   - 注意：代价要具体，不要写“尚缺乏研究”而要说“缺乏研究导致无法有效预测……”。

3. **点句**：每一个大段落（或小节）的开头，写一个点句，预告该部分的主要内容和论点。不要写“本节将介绍……”，而是直接陈述核心观点。

4. **角色与动作**：让主语是角色（研究对象、方法、数据、研究者），动词是动作。避免“对……进行了分析”这类名词化冗余。
   - 坏：`对数据进行了统计分析，结果显示……`
   - 好：`我们分析了数据，结果显示……`

5. **被动语态**：学术写作中被动语态不是禁令，但要控制。如果施事者是你或你的团队，优先用“我们”；如果施事者不重要或需客观化，可以用被动，但要确保信息流畅通。
   - 例如：`样本被随机分为两组`（这里施事者不重要，被动合理）
   - 避免：`数据分析被执行`（改为“我们分析了数据”或“数据经过分析”）

6. **术语处理**：首次引入术语时，就地解释（一句话+例子）。不要假设读者知道所有缩写和行话。用具体意象替代抽象名词（“认知负荷”优于“处理负担”）。

7. **连贯**：段落内主题串保持一致。每句开头放旧信息，结尾放新信息或强调点。

8. **简洁**：删除“值得注意的是”“需要指出的是”“在一定程度上”等填充语。用动词代替名词化（“相关分析”可保留，但“进行相关性分析”改为“分析相关性”）。

## 常用模板

### 引言模板（问题—代价—解答）

```
（共享语境）X 是……的重要问题。已有研究表明……（简要回顾）。然而，（问题条件）目前对 Y 的理解仍然有限。尤其是……（具体缺口）。（问题代价）如果不解决这一问题，将导致……（具体后果）。（解答/论点）本研究通过……，旨在回答……。我们提出……。
```

### 段落点句模板

```
本部分的核心发现是……。我们首先……，然后……，最后……。结果表明……。
```

## 禁用事项

- [ ] 不要用“众所周知”“显而易见”开头
- [ ] 不要用“近年来，越来越多的学者关注……”作为万能开头（直接进入主题）
- [ ] 不要堆砌“在一定程度上”“可能”“似乎”等模糊缓冲（除非确实需要表达不确定性）
- [ ] 不要写“本文将介绍……”“本章将讨论……”等元话语
- [ ] 不要用“对……进行了……”冗余结构
- [ ] 不要让主语抽象化（“数据分析结果显示” 改为 “我们分析数据发现”）
- [ ] 不要过度使用“其”“该”“此”等文言指代词，适当用“它”“这”“那”
