# 误用词与伪规则参考

> 误用词表精选自 Strunk & White；伪规则表精选自 Pinker。
> 当你不确定某个词用法、或遇到“写作规则”无法判断真假时查阅。

## 使用场景

- 修改时遇到拿不准的用词。
- 面对一条写作规则，不确定是否该遵守。

## 1. 英文误用词速查（精选）

| 误用/冗余 | 修正 |
|---|---|
| `the question as to whether` | `whether` |
| `there is no doubt but that` | `no doubt` |
| `owing to the fact that` | `because` |
| `in spite of the fact that` | `though` |
| `call your attention to the fact that` | `remind you` |
| `full and complete` | `complete` |
| `each and every` | `each` |
| `in the event that` | `if` |
| `make an appearance` | `appear` |
| `is applicable` | `applies` |
| `make a discovery` | `discover` |
| `conduct an analysis` | `analyze` |
| `with the exception of` | `except` |

## 2. 中文常见冗余与欧化表达

| 冗余/欧化 | 改为 |
|---|---|
| 进行了讨论 | 讨论了 |
| 作出贡献 | 贡献（或“作出贡献”根据语境） |
| 实施改革 | 改革 |
| 具有重要性 | 很重要 / 重要 |
| 在……的背景下 | 删除或改为具体表述 |
| 随着……的发展 | 删除或改为具体表述 |
| 众所周知 | 删除或给出具体事实 |
| 毋庸置疑 | 直接断言 |
| 显而易见 | 删除 |
| 非常、高度、极其 | 删除或换强动词 |
| 完全彻底 | 彻底 |
| 正是因为……的原因 | 正是因为 |
| 原因是因为 | 原因是 / 因为 |

## 3. 伪规则速查（不要遵守）

| 伪规则 | 真相 |
|---|---|
| 禁止分裂不定式（英文） | 英语不定式是两个词，可以分裂 |
| 禁止介词悬空（英文） | 介词在句尾已有 600 年历史 |
| 禁止单数 they（英文） | 乔叟、莎士比亚都用过 |
| 禁止以 and/but 开头 | 完全正常 |
| 禁止 "less" 用于可数名词 | “one less car” 正常 |
| 禁止 "very unique" | “独特”有程度差异 |
| 中文必须严格区分“的、地、得” | 现代汉语已趋于合并，不必强求 |
| 中文不能用“被”字句 | “被”字句可以，但要注意语境和色彩 |
| 中文不能用“进行” | “进行”可以，但避免滥用于冗余结构调整 |

## 4. 判断规则真伪的标准

一条规则应被遵守，如果：
- 被优秀的当代作者普遍遵守。
- 违反它会让读者困惑或分心。
- 它是对直觉语法现象的合理延伸。

一条规则应被忽略，如果：
- 基于拉丁语类比（如分裂不定式禁令）。
- 基于词源谬误（如 decimate 只能表示“杀死十分之一”）。
- 被伟大作家长期无视（如介词悬空）。
- 遵守它反而让句子更笨拙。

中文环境中同样适用此标准。
