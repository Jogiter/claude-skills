# 邮件与公文写作提示

> 使用场景：撰写或修改工作邮件、通知、公告、信函等日常事务性文本。
> 目标：简洁、直接、礼貌，让收件人快速理解并采取行动。

## 核心要点

1. **姿态**：你是沟通者，不是文学作者。邮件的目的是传递信息或请求行动。要把对方当聪明人，不绕弯子。

2. **主题行**：直接概括邮件内容，让收件人决定何时打开。例如“会议时间变更：本周三下午三点”。

3. **开头**：一句话说明来意。不要“见信好”“你好”之后绕一大圈才说正事。

4. **正文**：如果多个问题，分点列出。每段一个要点。

5. **结尾**：明确期望的下一步行动。例如“请在本周五前回复确认”或“如有问题请随时联系”。

6. **语气**：礼貌但不卑微。用“你”和“我”，避免“贵方”“我方”。适度使用“请”“谢谢”。

## 常用模板

### 请求类邮件

```
主题：请求批准XX项目的预算

你好 [name]，

我想请求批准 XX 项目的预算，金额为 XX 元。该项目计划在 [时间] 启动，预计需要 [时间] 完成。预算明细见附件。

如果你方便，请在本周内回复确认。谢谢！

[name]
```

### 通知类邮件

```
主题：关于XX会议时间变更的通知

各位同事，

原定于本周五下午的 XX 会议时间改为下周二上午 10 点，地点不变。请大家调整日程。

如有冲突请及时告知。

谢谢！
```

## 禁用事项

- [ ] 不要在邮件开头用“你好”后加无关寒暄
- [ ] 不要写“请注意查收”作为结尾（可以写“请查收”或不写）
- [ ] 不要滥用“特此通知”“兹证明”等公文套话
- [ ] 不要用太多“非常”“十分”等强调词
- [ ] 不要用被动语态隐藏责任人（“错误被作出了”→“我犯了错误”）
