# 术语速查表

> 中英文术语对照与定义。

| 术语（英文） | 术语（中文） | 定义 |
|---|---|---|
| Character | 角色 | 句子中做事的实体，通常应在主语位置 |
| Action | 动作 | 角色所做的事，应体现为动词 |
| Nominalization | 名词化 | 从动词/形容词转化来的抽象名词 |
| Agent | 施事者 | 动作的来源 |
| Topic | 话题 | 句子“关于”什么，常在句首（中文更突出） |
| Topic String | 主题串 | 句首反复出现的相关概念 |
| Theme | 主题 | 贯穿段落的关键概念群 |
| Cohesion | 凝聚力 | 句子之间的衔接 |
| Coherence | 连贯性 | 整段/全文的整体统一感 |
| Stress Position | 强调位 | 句尾，读者注意力最强的位置 |
| Shared Context | 共享语境 | 引言开头给读者的背景 |
| Condition + Cost | 条件 + 代价 | 问题的两个组成部分 |
| Point Sentence | 点句 | 单位开头段末的论点句 |
| Concision | 简洁 | 用足够的词，不多不少 |
| Hedge | 缓冲词 | 降低确定性的词（seem, may, 似乎） |
| Intensifier | 强调词 | 增加确定性的词（clearly, obviously） |
| Resumptive Modifier | 回指修饰语 | 重复关键词后继续扩展 |
| Summative Modifier | 总结修饰语 | 用概括词回指前文 |
| Free Modifier | 自由修饰语 | 评论主语状态的尾部修饰 |
| Chiasmus | 交错 | AB:BA 的镜像结构 |
| Periodic Sentence | 悬置句 | 把主句拖延到句尾 |
| Curse of Knowledge | 知识的诅咒 | 专家难以想象非专家的理解状态 |
| Classic Style | 古典风格 | 以透明窗户呈现真理的姿态 |
| Topic Chain | 话题链 | 中文中连续话题保持一致的连贯手段 |
| Zero Anaphora | 零指代 | 省略主语而上下文仍清晰的现象 |
| Pseudo-rule | 伪规则 | 没有依据或过时的写作禁忌 |
