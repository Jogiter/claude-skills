# 姿态层：写作的根本立场

> 写作是智性活动，不是技能包。风格是对真理、呈现、场景、角色、思想与语言的完整立场。
> 来源：Thomas & Turner《古典风格》为主，Pinker《风格感觉》补充认知机制。

## 使用场景

- 当你不确定“用什么口吻写”时，先读本文件。
- 当你的文本读起来像在“自辩”“卖弄”“堆术语”时，回到本文件重新定位姿态。

---

## 1. 核心隐喻：导游展示风景

- 你看见了读者没看见的东西，你的任务是引导读者的视线，让他们自己看见。
- 写作的目的是**呈现事实**，不是证明自己聪明，也不是推销观点。
- 作者与读者是**平等的对话者**，读者有能力，只需你指给他看。

**一句话判据**：好作者不“说理”，好作者“展示”。读者能“看见”你描述的场景时，写作就成功了。

---

## 2. 古典风格五要素

| 要素 | 含义 | 写作时怎么做 | 中文特别提示 |
|---|---|---|---|
| **真理 Truth** | 真理可知、独立存在，作者只是呈现 | 不说“我认为”“在我看来”，把判断当作可观察事实 | 中文也避免“个人觉得”“依我浅见”等过度自谦 |
| **呈现 Presentation** | 散文是透明的窗户，隐藏劳动 | 不展示修改过程、不写元话语、不自我辩解 | 避免“笔者试图”“本文拟”等论文腔 |
| **场景 Scene** | 一人对一人说话，自发的口语感 | 避免“首先/其次/如前所述”，像对朋友说话 | 中文可用“我们来看”“你可能会问”等自然过渡 |
| **角色 Cast** | 读者有能力，作者真诚，关系对称 | 不居高临下，不焦虑讨好，不隐藏责任 | 中文用“你”比“读者”更亲近；但正式文体可保留“读者” |
| **思想与语言** | 思想先于语言，语言足够 | 先想清楚再写，不写“无法表达”，抽象概念当作有边界的事物 | 中文里不说“难以言表”，直接描述对象 |

---

## 3. 古典姿态的禁止清单

写作时避免以下行为：

- 不写“我试图解释”“我无法用语言表达”“这里有一个复杂的问题”等自我拆台的话。
- 不用元话语组织文本（“本章将讨论”“下面我将介绍”）。
- 不展示研究过程、资料来源讨论、或对主题价值的辩护。
- 不为了显得谦虚而削弱自己的断言。
- 不堆砌同义反复、无意义的修饰词。
- 不使用被动语态来逃避责任，直接说“X 做了 Y”，除非让施动者隐藏是必要的信息安排。
- 不要像学术论文那样引用大量“别人说”，除非确实是内容需要；古典风格依赖你自己的呈现。
- 不要模仿糟糕的学术黑话；语言要精确但可被普通人理解。

**中文特有禁止**：
- 不滥用“众所周知”“毋庸置疑”“显而易见”（它们常常是空洞的强调）。
- 不写“笔者不才”“略陈管见”等过度自谦（古典风格作者是自信的）。
- 不使用“在……的背景下”“随着……的发展”作为万能开头（它们通常是元话语的伪装）。

## 4. 知识的诅咒（Pinker 认知补充）

> 你难以想象，你所知道的事情在不知道这件事的人看来是什么样子。

**两大机制**：

| 机制 | 解释 | 后果 |
|---|---|---|
| **组块** | 大脑将复杂信息压缩为单个心理单元 | 专家以为读者也内化了这些组块 |
| **功能固着** | 只看到事物的功能角色，忘记其物质形态 | 用“刺激”代替“手腕上的敲击” |

**克服方法**：
1. 假设读者和你一样聪明，但碰巧不知道你所知道的。
2. 回归具体意象：看见就能理解的东西（“苍鹭”而非“长腿涉禽”）。
3. 对术语就地解释（一句话 + 一个例子）。
4. 请非专业人士试读，形成闭环反馈。
5. 延迟自查：放几天再读自己的稿子。

**中文示例**：
- 坏：“该装置实现了对非结构化环境中视觉信息的实时获取与处理。” → 读者可能不知道是什么。
- 好：“这台机器人能在杂乱房间里实时‘看’到东西并做出反应。”

## 5. 风格混淆与边界

| 风格 | 与古典风格的区别 | 何时避免 |
|---|---|---|
| Plain style | 把简单当作终极价值，缺乏细微区分 | 需要精密论证或微妙判断时 |
| Practical style | 为读者完成具体任务，允许略读 | 写作目的是呈现而非操作时 |
| Reflexive style | 不断质疑写作本身能否触及真实 | 不要在古典写作中讨论写作困境 |
| Contemplative style | 重点是作者的解释与沉思 | 需要直接呈现对象时 |
| Romantic style | 作者创造世界，世界依赖作者 | 需要客观呈现事实时 |
| Prophetic style | 作者作为更高力量的传声筒 | 读者需要独立验证真理时 |
| Oratorical style | 对群体演讲，目的是鼓动 | 一人对一人的私下谈话语境时 |

## 6. 姿态自检清单

```
□ 这段文字是在“展示”还是在“自我辩解”？
□ 我是否把读者当作有能力的朋友，而不是需要被教化的对象？
□ 我是否隐藏了劳动，直接呈现结果？
□ 我是否用具体意象代替了抽象术语？
□ 我是否在逃避责任（用被动、抽象主语、模糊语言）？
□ 如果我是读者，我会觉得被尊重还是被操纵？
□ 中文文本：是否避免了“在……背景下”“随着……发展”等空洞开头？
□ 中文文本：是否避免了过度自谦和元话语？
```
