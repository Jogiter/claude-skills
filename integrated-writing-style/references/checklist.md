# 终检清单

> 交付前使用。30 秒快速清单 + 完整分级清单。

## 使用场景

- 完成写作或修改后，最后检查一遍。
- 不希望逐条细读时，先过 30 秒清单。

---

## 30 秒快速清单

```
□ 主要角色是否作主语？
□ 主要动作是否是动词？
□ 每句开头是否是读者已知的信息？
□ 每句结尾是否是重要的新信息？
□ 段落是否有清晰的主题串？
□ 引言是否包含“问题”及其“代价”？
□ 每段是否有“点句”预告后面内容？
□ 是否删除了所有冗余和空词？
□ 长句是否“从短到长”组织？
□ 我是否在用风格帮助读者而非操纵读者？
□ 有没有僵尸名词？（“做出确认”之类）
□ 有没有元话语开头？（“本章将讨论”）
□ 有没有模糊缓冲？（“几乎”“显然”）
□ 主谓之间、动词宾之间有没有错误的逗号？
□ 并列结构是否平行？
□ 名词短语是否向左堆积？
□ 否定是否先立后破？
□ 用词是否精确？（不确定就查词典）
□ 大声朗读是否流畅？
□ 是否忽略了伪规则？（分裂不定式、介词悬空、单数 they）
```

## 完整分级清单（按工作流阶段）

### 阶段 0：姿态
- [ ] 文本是在“展示”而非“卖弄”或“自辩”
- [ ] 作者真诚、平等、不隐藏责任
- [ ] 没有自我拆台的话（“我试图”“无法表达”）
- [ ] 没有元话语（“下面我将”）
- [ ] 中文：没有“在……背景下”“随着……发展”等空洞开头

### 阶段 1：清晰
- [ ] 每个句子的主语是动作执行者（角色作主语）
- [ ] 主要动作体现在动词上
- [ ] 名词化适当（首次提示用动词，回指可保留）
- [ ] 被动语态有正当理由
- [ ] 中文：没有“进行/作出 + 名词化”冗余
- [ ] 中文：没有奇怪欧化被动

### 阶段 2：连贯
- [ ] 每句开头与上句有信息连接（旧→新）
- [ ] 段落主题串集中（2-3 个相关概念）
- [ ] 句尾是重要新信息
- [ ] 中文：主题链通过代词/省略/话题前置实现，而非重复名词

### 阶段 3：形式
- [ ] 引言包含共享语境 → 问题（条件+代价）→ 解答
- [ ] 读者的“So what?”已回答
- [ ] 每段有明确点句
- [ ] 点句预告了关键概念
- [ ] 中文：问题代价用“如果不……就会……”表达

### 阶段 4：简洁与形状
- [ ] 无意义词已删除
- [ ] 重复对已删除
- [ ] 可推断内容已删除
- [ ] 短语已换成单词
- [ ] 否定已改肯定（适当处）
- [ ] 长句主句在前
- [ ] 没有向左分支堆积（定语不超过 2-3 层）
- [ ] 没有中心埋置从句
- [ ] 中文：没有冗余“的”字结构；短句/长句搭配合理

### 阶段 5：优雅与伦理
- [ ] 重要词在句尾
- [ ] 平行结构/平衡句法运用得当
- [ ] 没有通过语态隐藏责任
- [ ] 读者能合理时间内理解
- [ ] 中文：没有滥用“被”“遭到”淡化责任

---

## 标注错误类型的速记符号（可选，供修改时使用）

- `[角色]`：角色未作主语
- `[动作]`：动作未作动词
- `[名词化]`：不必要名词化
- `[被动]`：被动语态无正当理由
- `[信息流]`：新旧信息顺序不当
- `[主题链]`：主题串断裂
- `[冗余]`：多余词
- `[形状]`：长句结构差
- `[伦理]`：隐藏责任或操纵读者
- `[中文欧化]`：翻译腔问题
